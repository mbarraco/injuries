# Glossary

## Purpose

Define terms that otherwise cause silent analytical errors.

## Overview

Terms follow source grain rather than colloquial football language.

## Table of Contents

1. Entity terms
2. Time terms
3. Evidence terms

| Term | Definition |
|---|---|
| Availability observation | A vendor record that a player was marked unavailable or questionable for a fixture. |
| Authority | The best endpoint producer for one specified fact and grain. |
| Coverage | Catalogued claim that a feature is available for a league season; it is not a row count. |
| Fixture revision | A retained changed response for the same fixture identity. |
| Grain | What one stored row represents. |
| League season | A season integer qualified by a league identity. |
| Snapshot | A value observed at retrieval time whose source may later change it. |
| Spell | A real-world interval of injury or sidelining; not directly identified by `/injuries`. |
